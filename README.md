
# AttendX-Test-Scripts

## Project Description
This repository contains sample test scripts
for the AttendX Student Attendance App.

## Files
- login_test.py: Tests valid login and empty username.
- attendance_test.py: Tests attendance marking and
  missing student ID.

## Requirements
- Python 3
- Git

## How to Run
python login_test.py
python attendance_test.py

## Purpose
To practice version control using Git and GitHub,
including commits, pushes, pulls, and Git history.
